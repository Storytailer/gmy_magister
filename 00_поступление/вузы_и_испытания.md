# 🏛 Вузы, направления и вступительные испытания

> ⚠️ Правила приёма меняются каждый год. Данные ниже — по кампании 2026 (проверено на официальных сайтах в августе 2026). **В сентябре 2026 и мае 2027 перепроверить!**

## Целевое направление

**38.04.04 «Государственное и муниципальное управление»** (магистратура)

Наш бэкграунд: 39.03.03 «Организация работы с молодежью» — смежное гуманитарное направление, поэтому вступительные сдаём как «свои» экзамены вуза (не ЕГЭ).

---

## 1. МГУ — Факультет государственного управления (ФГУ) 🎯 приоритет

- Сайт: https://spa.msu.ru · Поступающим: https://spa.msu.ru/postuplenie/magistratura/
- Тел. ПК: +7 (495) 939-35-21, pk@spa.msu.ru
- ~23 магистерские программы по 4 направлениям; у ГМУ — свой набор программ.

**Вступительные испытания (по результатам приёма-2026, выбирается 1 предмет из набора):**
| Предмет | Формат |
|---|---|
| Основы государственного и муниципального управления | письменно |
| Политология | письменно |
| Менеджмент / Менеджмент на англ. | письменно |
| Основы управления персоналом | письменно |

→ Наш главный фокус: **«Основы ГМУ (письменно)»** — программа испытания публикуется на сайте ФГУ весной. Экзамены проходят в августе (в 2026: 12–18 августа).

**Бонусы:** Универсиада «Ломоносов» (см. олимпиады.md) учитывается ЦПК МГУ при приёме в магистратуру.

## 2. РГСУ (Российский государственный социальный университет)

- Сайт: https://rgsu.net → Абитуриенту → Приемная кампания → Вступительные испытания
- Магистерские программы по 38.04.04, напр. «Муниципальное управление и местное самоуправление».
- Испытание: комплексный письменный экзамен по направлению (программа публикуется весной). Практикуется дистанционная сдача.

## 3. РУДН имени Патриса Лумумбы

- Сайт поступления: https://www.rudn.ru/admissions
- Программы ГМУ (в т.ч. на эколого/управленческих подразделениях), бюджетные места есть.
- Испытание: письменный экзамен по направлению / иногда конкурс диплома с отличием + портфолио. Проверить перечень для конкретной программы в разделе «Магистратура».

## 📋 Чеклист документов (начать собирать в апреле–мае 2027)

- [ ] Диплом бакалавра + приложение (оригинал/копия)
- [ ] Паспорт, СНИЛС
- [ ] Фото 3×4 (цифровые)
- [ ] Индивидуальные достижения: аттестаты олимпиад, грамоты, публикации (портфолио)
- [ ] Медсправка (если требуется по правилам вуза)
- [ ] Заявления подаются через Госуслуги / сайты вузов (июнь 2027)
