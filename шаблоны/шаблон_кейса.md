<!-- 150–300 слов: контекст, действующие лица, проблема, данные -->

## Задания
1. Сформулируй проблему и цель (SMART).
2. Предложи 2–3 альтернативных решения.
3. Выбери оптимальное, обоснуй (критерии!).
4. Опиши план внедрения и риски.
5. Как будешь оценивать результат?

## ⏱ Регламент
- Разминочный: 30 мин · Недельный: 60 мин · Олимпиадный: 3 часа

## ✍️ Структура идеального решения (запомнить!)
```
1. Вводная: переформулировка проблемы (2–3 предложения)
2. Нормативная база: какие законы/документы применимы
3. Цель и критерии успеха
4. Альтернативы → выбор по критериям
5. Дорожная карта: шаги, сроки, ресурсы, ответственные
6. Риски и их снижение
7. Показатели результата
```

## 🔍 Самопроверка после решения
- [ ] Есть ли нормативные ссылки?
- [ ] Цель измерима?
- [ ] Альтернатива хотя бы одна отвергнута обоснованно?
- [ ] Риски названы?
