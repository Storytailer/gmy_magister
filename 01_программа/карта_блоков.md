## Формат каждой недели (единый)

```
Неделя N. [Тема]
├── Пн-Вт: 📖 Лекция-конспект (генерирую по запросу)
├── Ср:    🎬 Видеолекция (поисковый запрос → ссылка)
├── Чт-Пт: 🧩 Кейс / семинар-вопросы
├── Сб:    ✅ Тест самопроверки (10 вопр., с ответами)
└── Вс:    ⏱ СРЕЗОВЫЙ ТЕСТ НЕДЕЛИ (зачёт ≥70%)
```

Конец блока: 🏁 Большой срез (40–60 вопросов + кейс-задача, 90 минут).
