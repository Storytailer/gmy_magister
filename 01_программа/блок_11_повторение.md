## План недели за неделей

### Недели 41–42: программы вступительных испытаний
- [ ] Скачать официальные **программы вступительных испытаний 2027** каждого вуза (публикуются весной):
  - МГУ ФГУ: spa.msu.ru → Поступающим → Магистратура
  - РГСУ: rgsu.net → Абитуриенту
  - РУДН: rudn.ru/admissions
- [ ] Составить сводный перечень тем по каждой программе (просить меня: *«Сведи программы трёх вузов в одну таблицу»*)
- [ ] Отметить темы с пробелами → точечное повторение из блоков 1–10

### Неделя 43: письменная техника ответа
Тренируем структуру развёрнутого ответа:
```
Определение → Классификация/состав → Нормативная база → 
Пример из практики → Актуальная проблема → Вывод
```
- Каждый день: 1 вопрос из программы билета письменно за 20 минут
- Взаимная проверка друг друга + мой разбор по запросу

### Неделя 44: пробные экзамены
- 2 полных билета в неделю в реальном формате (генерирую варианты)
- Экзамены РГСУ и РУДН (обычно июль) — следить за расписанием приёмных комиссий!
