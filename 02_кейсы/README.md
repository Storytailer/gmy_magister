# 🧩 Копилка кейсов

Кейсы решаются **письменно**, затем сверяем решения друг с другом и просим меня дать эталонный разбор.

## Как пополнять копилку
1. Каждая неделя даёт минимум 1 кейс (лежит в файле блока).
2. Реальные новости = готовые кейсы: взял статью про регион/город → примени структуру решения.
3. Демоварианты финалов «Я — профессионал» и Универсиады — сюда же.

## Критерии оценки решения (шкала 10 баллов)
- 0–2: проблема понята неверно / нет структуры
- 3–5: есть структура, нет нормативной базы и альтернатив
- 6–8: полная структура, есть нормативка, альтернативы, риски
- 9–10: + измеримые показатели и оригинальность решения
